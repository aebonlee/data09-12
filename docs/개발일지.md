### 결정과 이유

- **메일은 초안 파일(.eml, `X-Unsent: 1`)만 만듭니다.** Outlook에서 열면 보내기 전 상태로 열려, 사람이 확인하는 단계가 남습니다. 사내 메일 계정 연동 없이 바로 쓸 수 있습니다. PO PDF는 첨부로 넣습니다.
- **ZIP은 직접 만들었습니다(무압축).** 초안 여러 건을 한 번에 받기 위해서이며, 외부 라이브러리를 늘리지 않으려고 `logic.js`에 CRC32·ZIP 작성기를 넣었습니다.
- **PDF 본문은 pdf.js로 브라우저 안에서 읽습니다.** 스캔본이면 글자가 없어 파일명으로만 찾고, 화면에 「본문 글자 없음」을 표시합니다. `file://`에서는 Worker 대신 대체 방식으로 돌아가는 것을 확인했습니다.
- **열 이름은 짐작 + 연결 화면**입니다. 흔한 영문·국문 열 이름으로 먼저 맞추고, 사용자가 고친 연결은 저장해 다음 파일에 다시 씁니다. 표 위에 제목 줄이 있는 엑셀을 위해 머리글 행 번호를 바꿀 수 있습니다.
- **OC 수령일 반영은 사람이 확인합니다.** 메일 분류는 「업체 메일 + 대장의 PO 번호 + OC 낱말」이 모두 있을 때만 후보로 올리고, 체크한 것만 반영합니다. 이미 수령일이 있는 PO는 건드리지 않습니다.
- **Weekly Order Status 비교 기준은 PO + 라인(없으면 품번)**입니다. 같은 날짜를 다른 형식으로 적은 경우(예: `2026-10-05`와 `05-Oct-2026`)는 변경으로 보지 않습니다. 「03/04/2026」처럼 월·일 순서가 모호한 형식은 기본을 월/일로 두고 화면에서 일/월로 바꿀 수 있습니다.
- **판단 기준은 모두 설정값**입니다. 처음 값(OC 대기 3일, EXW 임박 7일, EXW 허용 0일, 중량 오차 0kg·0%)은 화면이 비지 않게 넣은 임시 기본값이며 사내 기준이 아닙니다.

### 가정(수강생 확인 필요)

- A/N = Arrival Notice
- OC 수령일 = 공급사 회신 메일을 받은 날(OC 문서의 기재 일자와 다를 수 있음)
- OC 접수율 = OC 수령 건 ÷ 송부 건, EXW 준수율 = (실제 출고일 ≤ 약속 EXW DATE + 허용 일수) 건 ÷ 출고 완료 건, 평균 지연일 = 출고 완료 건의 지연일 평균(이르면 0일) — HD360의 산식과 같은지 확인 필요
- Weekly Order Status의 Promise Date = 공급사 약속 출고(또는 납기)일 — 관리 대장의 약속 EXW DATE와 같은 값인지 미확인이라 자동으로 대장에 반영하지 않았습니다
- Packing List 중량 열 = 행별 총중량(kg), B/L 중량과 같은 단위. 개당 중량이면 화면에서 「개당 중량」을 켭니다
- 기본 메일 문안은 일반적인 영문 예시입니다
