## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-12/**

설치·로그인·서버가 필요 없습니다. 올린 엑셀·PDF·메일은 브라우저 안에서만 읽고, 외부로 보내지 않습니다. 입력한 내용은 그 브라우저에 저장됩니다(다른 PC로 옮길 때는 「설정 → 백업 내려받기」).

로컬에서 쓰기

1. 이 저장소를 「Code → Download ZIP」으로 받아 압축을 풉니다.
2. `index.html`을 더블클릭해 크롬·엣지로 엽니다(인터넷 연결 없이도 동작합니다).
3. 처음이면 「예시 데이터 불러오기」로 둘러본 뒤, 「설정」에서 보내는 사람·판단 기준을 바꾸고 「업체」에서 실제 Contact List를 올립니다.

회사 PC에서 파일로 열 때 막히는 경우에만, 폴더에서 `python -m http.server 8000` 을 실행하고 `http://localhost:8000` 으로 엽니다.

개발자 확인

- 계산 로직 시험: `node test/logic.test.mjs`
- 예시 파일 다시 만들기: `node scripts/make-samples.js` (`samples/` 의 `예시데이터_*` 파일)

## 1단계 구현 범위

기획서 5장 기능 표 기준입니다. 판단 기준(OC 대기 일수, EXW 임박·허용 일수, 중량 허용 오차)과 메일 문안은 모두 「설정」에서 바꾸는 값이며, 처음 값은 임시 기본값(가정)입니다.

- [x] 업체 연락처 조회 — Contact List 엑셀 가져오기(열 연결 화면), 업체명·코드·담당자·이메일 검색, 수신 주소 복사
- [x] PO–업체 자동 매칭 — PO PDF 여러 개의 파일명·본문에서 PO 번호(영문 1자 + 숫자 9자리 기본)·업체 찾기, 못 찾은 건 표시·직접 고치기(PO 번호 규칙은 설정에서 정규식으로 변경)
- [x] 구매발주서 본문 읽기 — 품목 줄(품번·수량·단가·금액·납기·Mfr 품번)·Contract Amount·인코텀즈, 검산 경고. PDF가 안 열리면 PDF 뷰어에서 복사한 글 붙여넣기
- [x] 발주 메일 초안 일괄 생성 — 업체별 수신·참조·제목·영문 본문·PO PDF 첨부가 든 .eml, 같은 업체 PO는 한 통에 묶기(실제 메일 문안 구성), ZIP 묶음(자동 발송 없음)
- [x] PO·선적·A/N 관리 대장 — 송부일·OC 수령일·약속/실제 EXW DATE·ETD·A/N·선적서류 수신, 상태 표시(OC 미접수·EXW 임박·EXW 지연·서류 미수신), 엑셀 내보내기·가져오기
- [x] OC 수령 관리 — OC 수령일 기재(「OC 오늘 수령」 버튼·메일 분류에서 반영), 설정 일수 경과 OC 미접수 판정, OC 접수율
- [x] OC 미접수 팔로우업 — 업체별로 묶은 PO 목록이 든 팔로우업 초안(.eml), 본문 고치기·복사, 팔로우업 날짜 기록
- [x] EXW 준수율·평균 지연일 — 전체·업체별 표와 막대, 기간(송부일) 거르기, 엑셀 내보내기, 산식 화면 표기
- [x] 업체별 메일 분류(반자동) — .eml(여러 겹 MIME·첨부) 을 발신 도메인으로, 없으면 PO 번호로 업체 분류, 제목·본문·첨부 파일명의 PO 번호와 OC 낱말·OC 첨부로 OC 수령일 후보 제시 후 확인 반영, 업체별 폴더 ZIP·분류표 엑셀
- [x] OC 엑셀 대조 — 메일 첨부 또는 직접 올린 OC(.xls/.xlsx)의 OC 번호·OC DATE·품목을 PO 품목과 대조(수량·단가·공급사 품번·납기), OC DATE를 약속 EXW DATE로 반영
- [x] Promise Date 변경 확인 — Cummins Integrated Order Status 두 주차(한 파일의 두 시트도 가능) 비교, PO·품번·1OM#·SO# 로 줄 맞춤, 밀림·당김·취소·신규·빠짐, 한 주차뿐이면 파일 안 변경 기록(칸 안 `a=>b`, Remarks `a->b`), 엑셀 내보내기
- [x] Cummins 오더 현황 → EXW DATE — 분석 시트(「wk38 분석E」)에서 Status·구분(기본 Undispatched·HCE)으로 거른 줄의 Promise Date를 PO·Part No. 별로 대장에 입력, 분할 선적 날짜별 수량과 PO·OC 수량 대조, 노란 줄(EXW 변경) 표시, 일치 건 일괄·불일치 건 확인 후 반영, 반영 전/후 엑셀
- [x] Packing List–B/L 중량 대조 — Packing List 엑셀 또는 표 붙여넣기, 묶음(Invoice 등)별 합중량, B/L 중량 직접 입력, kg·lb 단위, 허용 오차 판정
- [x] 항차 체크리스트 — 항차 업무 매뉴얼 단계(PO 송부 → OC 접수 → L/C → 항차 입력 → 보세운송)를 PO마다 기록, ETA(ETD + 지역 평균 운송기간)·L/C 일정 계산
- [x] 업체별 체크리스트 — 업체마다 입력(구매발주서 조건 기본 항목 넣기), 발주·선적서류 요청 메일에 함께 표시
- [x] 상황별 Follow-up 메일 템플릿 — 납기(EXW) 확인·선적서류 요청·A/N 미수신 확인(빈칸 채우기, 생성형 AI 없음)
- [ ] 생성형 AI 문안 다듬기 — 2단계(외부 AI 사용 허용 확인 후)
- [ ] A/N 자동 관리·메일함 직접 연동·실제 일괄 발송 — 3단계(Outlook 연결 허용 확인 후)
- [ ] B/L·Packing List PDF 중량 자동 추출, Outlook .msg 읽기, HD360·SRM 자료 연결 — 2단계(양식 확인 후)
- [ ] 담당자 인수인계 한 장 요약 — 2단계

예시 데이터(`samples/예시데이터_*`, 화면의 「예시 데이터 불러오기」)는 모두 지어낸 값이며 실제 업체·거래와 관계없습니다.
